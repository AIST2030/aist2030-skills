# AIST2030-post-product-360-v1 效果案例（SkillHub 发布用，3 个）

> 以下案例均为本技能真实出片验证结果，非虚构示例。

### 案例 1 —— 核心能力（泸州传奇 3 角度 → 360° 环绕）

- **场景标题**：把 3 张不同角度的白酒产品图合成为 360° 环绕展示视频
- **场景描述**：用户拖入泸州传奇·鼎福荣尊白酒的 3 张产品图（正面 / 斜侧 / 顶部），说「生成一个泸州传奇的 360 视频」。技能解析 product_name=泸州传奇，匹配分类「酒水/饮料」，智能推荐运镜=环绕，调用 Agnes AI keyframe_animation（3 张关键帧插值）生成 8.4 秒 720p 环绕视频。
- **示例输入**：3 张图（正面 / 斜侧 / 顶部），触发短语「生成一个泸州传奇的 360 视频」
- **示例输出**：`https://platform-outputs.agnes-ai.space/videos/agnes-video-v2.0/task_bV4VFf2y5hcKpOQIt8a8PHIZXjE3u2zG.mp4`（1088×832，8.4s，≈2.46MB）
- **触发条件**：用户发送产品图 + 「生成一个[产品]的 360 视频」类触发词。

### 案例 2 —— 典型行业场景（酒水/饮料商品展示，进阶多角度）

- **场景标题**：电商详情页白酒 360° 展示（不同角度组合）
- **场景描述**：同一泸州传奇产品，取另一组 3 张角度（正面 / 斜侧 / 侧面），同样智能推荐运镜出片，验证技能对「不同角度组合」同样稳定产出，适合酒水/饮料行业商品标准化展示。
- **示例输入**：3 张图（正面 / 斜侧 / 侧面），「生成一个泸州传奇的 360 视频」
- **示例输出**：`https://platform-outputs.agnes-ai.space/videos/agnes-video-v2.0/task_7lgzyFTDQyv5q5CQ8IhqzTTQcqK353LQ.mp4`（前期同技能真实出片）
- **触发条件**：酒水/饮料、美妆、3C 等需要多角度看货的行业场景。

### 案例 3 —— 边界 / 约束说明

- **场景标题**：图片数量与速率约束的正确处理
- **场景描述**：
  - **图片数量**：Agnes keyframe_animation 仅支持 **2–3 张**不同角度图；<2 张 → 提示「至少 2 张不同角度图」；>3 张 → 自动选角度最均匀的 3 张。
  - **运镜选择**：20 种专业运镜可手动指定，或由 Agent 按产品分类智能推荐（如白酒→环绕/慢动作/微距）。
  - **速率限制**：免费用户 **1 RPM**，两次 POST 间隔 ≥60 秒；轮询不计入 RPM。
  - **失败处理**：超时/失败返回单行 `【执行失败】` + 原因，不反复刷新、不超量。
- **示例输入**：1 张图（不足）→ 提示补图；或 5 张图（超出）→ 取最均匀 3 张。
- **触发条件**：用户图片不合规、触发词缺失产品名、或命中速率限制时，据此给出边界提示。
