# AIST2030 逐字稿与PPT脚本 效果案例（case-template）

> 提供 3 个效果案例，供发布前核对与下游参考。

### 案例 1（核心场景）：把"什么是 AI Agent"扩写为录课稿

**输入**
lesson「什么是 AI Agent」objective=口述定义并区分 chatbot，source_cards=[1]

**预期输出要点**
- verbatim：800-1200 字口语逐字稿，含开场钩子与小结（如"你有没有问 chatbot 一个问题，答得漂亮但活儿还得自己干？[停顿]"）
- ppt_script：分页要点 + 讲师备注（如 页面 Agent vs Chatbot｜要点 被动应答 vs 自主执行｜备注 举订机票例子）
- quiz：1-2 道选择/判断，答案可由本节内容答对

### 案例 2（行业变体）：数据指标讲解节

**输入**
lesson「怎么看留存曲线」source_cards=[指标卡片]

**预期输出要点**
- 逐字稿含"看曲线拐点"的口语化讲解与互动提示
- PPT 要点匹配逐字稿节奏，不堆砌
- 测验考查对留存定义的理解

### 案例 3（边界场景）：素材单薄时不出错

**输入**
source_cards 内容仅一句话要点

**预期输出要点**
- 逐字稿忠于现有内容，不超纲编造细节
- quiz 仅基于可答内容出题，标注"需补充素材后扩展"
