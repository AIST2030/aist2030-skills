# 竖屏字幕排版规范（1080×1920）

## 一、平台安全区

抖音 / 快手 / 视频号的界面元素会遮挡画面：

| 区域 | 位置 | 建议 |
|---|---|---|
| 头像 + 关注 | 右侧中上部 | 字幕**不要**横向铺满 |
| 点赞 + 评论 + 收藏 | 右侧中下部 | 同上 |
| 剧集/合集信息 | 左下 | 字幕要抬高 |
| 文案 / 音乐信息 | 底部约 200-300px | **字幕必须上移** |

本项目默认 `margin_v = 320`（距底部像素），`margin_h = 90`。

## 二、断句：视觉宽度单位

中文和英数字符的视觉宽度差别很大，不能按字数算：

```python
def visual_units(text):
    # 中文/全角 = 1.0，英数 = 0.58
```

**上限 15 视觉单位**（1080 宽、字号 62 时约 930px，留边距）。

按 `visual_units` 断句而非按字符数，否则会出现「中文一行很挤、英文一行很空」。

### 断句优先级

1. 优先在标点后断：`，。！？、；：…—`
2. 标点找不到就在接近上限处硬断
3. 孤字行并回上一行

参考自 `stage6_subs.py: split_long()`。

## 三、为什么用 ASS 而不是 SRT

| 能力 | SRT | ASS |
|---|---|---|
| 多行混排 | 弱 | `{\an2\pos(x,y)}` 精确控制 |
| 描边/阴影 | 靠 force_style | 样式表完整定义 |
| 逐词高亮 | ❌ | ✅（`\k` 标签） |
| 动画 | ❌ | ✅（`\t` `\move` `\fad`） |

短剧硬字幕要用 ASS：`Style: Main,Microsoft YaHei,62,&H00FFFFFF,...,1,3,1,2,90,90,320,1`

- `Alignment=2` 底部居中
- `Outline=3` 描边 3px（白字黑边，任意背景下都看得清）
- `MarginV=320` 抬高避让

## 四、烧录：fontsdir 必须给

```bash
ffmpeg -i in.mp4 -vf "ass='C\\:/path/final.ass':fontsdir='C\\:/Windows/Fonts'" \
  -c:v libx264 -crf 19 -c:a copy out.mp4
```

⚠ **漏掉 `fontsdir` 的后果**：libass 找不到中文字体 → **渲染成方块豆腐**。
Windows 字体目录是 `C:\Windows\Fonts`（在滤镜串里要写成 `C\\:/Windows/Fonts`）。

⚠ **Windows 盘符冒号必须转义**：滤镜串里 `C:/...` 会被当成选项分隔符，
必须写成 `C\\:/...`。

## 五、时间码重映射 ★最容易错

多段来自不同集、顺序重排后，**原 ASR 时间码全部作废**。

```
成片时间 = 该段在成片上的起点 + (台词原时间 − 该段原片入点)
```

举例：第 3 句来自 ep02，原片 85.2s；它被放在 EDL 第 3 段，
该段原片入点 60.0s，在成片里从 12.4s 开始：

```
成片时间 = 12.4 + (85.2 − 60.0) = 37.6s
```

漏掉这步 → 字幕与声音完全错位，且「看起来字幕挺对」很难一眼发现
（文字内容是对的，只是时间不对）。

### 过滤规则

只取与该段 `[final_in, final_out]` 有实际重叠（>0.12s）的台词。
重叠太短的丢弃——那通常是跨段的半句，字幕做出来会突兀。

### 重叠检测

相邻字幕重叠超过 0.3s 视为异常，会在 S7 报告里列出。

## 六、时间码格式

| 用途 | 格式 | 工具 |
|---|---|---|
| 剪辑清单 | `HH:MM:SS:FF`（帧） | `stage3_edl.py: timecode()` |
| ASS 字幕 | `H:MM:SS.CC`（厘秒） | `stage6_subs.py: ass_ts()` |
| ffmpeg `-ss` | 秒（带小数 6 位） | — |

**秒 → 帧一定要量化**：`round(t × fps)`。浮点数累积误差会让「精确剪辑」名不副实。

## 七、原片已有字幕怎么办

⚠ **本项目实测遇到的坑**：部分短剧原片**已烧录中文字幕**，
再加一层 ASS 字幕会双重字幕，画面上下两行字，观感很差。

三个方案：

| 方案 | 做法 | 适用 |
|---|---|---|
| A. 保留原字幕，不加新字幕 | `--no-subs` | 原字幕样式已符合要求 |
| B. 遮盖原字幕区域 | 用 `drawbox` 盖住底部字幕带，再烧新字幕 | 原字幕在固定位置 |
| C. 加在顶部 | `MarginV` 改大 + `Alignment=8`（顶部居中） | 快速方案，但顶部常有字幕 |

判断：先抽几帧看原字幕在哪（`stage1` 的联系表就能看出）。

## 八、字号参考

| 字号 | 适用 |
|---|---|
| 52-58 | 长句、多行 |
| 62-70 | 单行短句（默认 62） |
| 76+ | 钩子大字（3 秒内消失的那种） |

字号 >75 时一行放不下 8 个中文字，横幅式钩子文案要单独处理。
