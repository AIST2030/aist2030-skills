# 去重与合规

## 一、2026 年平台查重的真实机制

抖音是**三重核验**：

| 维度 | 判据 | 备注 |
|---|---|---|
| 画面指纹 | 关键帧特征 + **运动轨迹分析** | 2026 年已升级 |
| 音频指纹 | 人声波形 / 频谱 | 比画面更严格 |
| 文本 | OCR 识别画面文字 + 标题查重 | 字幕完全一致等于送指纹 |

### 抽帧为什么失效了

平台不再全片扫描，而是**抽取特定时间点的关键帧（I-Frame）**比对。
更关键的是它加了**运动轨迹分析**——无论你怎么抽帧，
物体移动的逻辑路径不变，算法照样能识别。

平台容忍度：

| 平台 | 检测重点 | 容忍度 | 违规后果 |
|---|---|---|---|
| 抖音 | 视觉指纹 + 音频频谱 | 极低 | 限流 → 重复提示 → 封禁 |
| 快手 | 画面构图 + 关键帧 | 中 | 降低推荐权重 → 违规提示 |
| B站 | 内容语义 + 社区举报 | 较高 | 版权警告 → 强制下架 |

## 二、去重手段有效性排序

| 手段 | 有效性 | 本项目实现 | 成本 |

### 平台比对的是内容指纹，不是文件指纹

改哈希、改分辨率、改码率都没用——必须改**画面本身**。

### 镜像的注意事项

镜像能改视觉指纹，但：
- ⚠ **不要镜像含明显文字、logo、人脸朝向的画面** —— 镜像后反而更可疑，人工复审会直接判搬运。
- ⚠ **不要对每段随机镜像** —— 会形成「批处理特征簇」，平台反而能识别出这是同一套模板产出的。

本项目 `standard` 档位的做法：**整片统一镜像**（一次到位，不像逐段那样露出批量痕迹），
不含文字台标的素材才用。

## 三、本项目的去重实现（`stage5_canvas.py`）

```python
DEDUP_GRADES = {
    "off":      "eq=saturation=1.00:contrast=1.00:brightness=0.000:gamma=1.00",
    "light":    "eq=saturation=1.06:contrast=1.04:brightness=0.010:gamma=0.99",
    "standard": "eq=saturation=1.12:contrast=1.08:brightness=0.018:gamma=0.97",
    "strong":   "eq=saturation=1.20:contrast=1.14:brightness=0.026:gamma=0.94",
}
```

⚠ **`brightness` 是加法偏移，不是乘法系数。**
`brightness=1.08` 会让每个像素 +275（超出 255 上限）→ 全片冲成纯白。
合法范围是 `-1 ~ 1`，默认 0。调亮用 `gamma`，不要用 brightness。

**随机种子**：`dedup.seed`（默认 AIST2030）。由 `sha256(seed|ep|index)` 派生确定性伪随机数，
保证重跑结果一致 —— 否则每次调色参数都会得到不同的画面，无法对比。

## 四、经验阈值

从业者经验（非官方）：

| 项 | 阈值 |
|---|---|
| 画面改动覆盖全片时长 | ≥ 60%，且必须是**结构性**（顺序/构图），不是表层调色 |
| 音频 | 至少一整条轨道被替换或重制 |
| 文案标题封面话题 | 全部重写，不复用原标题 |
| 变速 | 1.05-1.1（超过 1.15 人声失真，完播率崩） |

**自查**：把原视频和成片并排**静音播放**，路人一眼能看出是同一个内容 → 平台也能。
反过来，静音状态下节奏、构图、镜头顺序都变了 → 才算过关。

## 五、静默限流的自查信号

发完 2 小时内：播放量停在 200-500 不动、点赞几乎为零、
**但后台没有违规通知** —— 这八成是进了低质重复池，不是限流，是压根没给推荐。

真正的违规会弹通知。这种静默处理最坑人。

排查：创作者中心看「作品诊断」，若显示「内容重复度较高」说明画面或音频指纹仍命中。

## 六、⚠ 合规红线（必读）

### 著作权法怎么判

司法判断主要看三点：

1. **是不是为介绍评论而用**
2. **引用量是不是「少量必要」**
3. **会不会实质性替代原片观看**

著作权法保护影视作品的**复制权**与**信息网络传播权**。
「二创」不等于免责。

### 建议做法

| 做法 | 说明 |
|---|---|
| ✅ 优先官方白名单片库 | 抖音已与优酷/爱奇艺/芒果/搜狐开通合作二创白名单。片单内剧集剪辑二创，投诉概率极低，人工审核默认认可二创权益 |
| ✅ 能拿授权就拿 | 抖音部分影视二创计划、版权方开放授权包 |
| ✅ 原片段短而散 | 不剪核心高潮，不替原片讲完故事 |
| ✅ 自己的表达为主体 | 解说文案、观点拆解占主体，原素材只当配图 |
| ✅ 标明原作品 | 开头或评论区标明原作品名与作者 |
| ❌ 禁用高危素材 | 院线新片、平台独播付费短剧、刚上线网大、综艺独家片段 |
| ❌ 冒充原创 | 不用「全网首发」「完整版」 |

### 本流水线的定位

**这是技术工具箱，不替你判断授权状态。**
它解决的是「怎么剪得干净、字幕不错位、查重指纹有效」，
**不解决**「你有没有权利用这段素材」。后者是使用者的法律责任。

## 七、什么算有价值的二创

平台算法不只查重，也**鼓励有价值的内容**：

- 主题混剪：用统一情绪线串起来，选片逻辑是你的审美
- 盘点合集：Top10 角色 + 排序理由 + 个人点评
- 风格重制：滤镜/字幕/配音全换血
- 干货改编：拿别人视频当画面佐证，全程输出你的判断

**技术去重只是入场券，长期留住人的是视角。**
