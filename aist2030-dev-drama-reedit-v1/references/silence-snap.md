# 切点吸附：VAD vs 静音检测

## 一、问题的本质

目标：切点落在「没人说话」的地方，这样绝不会吞掉台词的字头或字尾。

两种技术路线：

| 路线 | 判据 | 适用素材 | 短剧表现 |
|---|---|---|---|
| `silencedetect` | 整体响度 < 阈值 | 口播、录屏、无 BGM 视频 | ❌ **失效** |
| `fsmn-vad` | 这一段**有没有人在说话** | 影视、短剧、任何带 BGM 素材 | ✅ 有效 |

## 二、为什么短剧上 silencedetect 会失效

短剧原片自带**持续 BGM 铺底**，实测本项目素材（`E:\BaiduNetdiskDownload` 5 集）：

| 阈值 | ep01 静音段 | ep02 | ep03 | ep04 | ep05 |
|---|---|---|---|---|---|
| -40 dB | 0 | 0 | 0 | 0 | 0 |
| -35 dB | 0 | 0 | 0 | 0 | 0 |
| -32 dB | 0 | 0 | 0 | 0 | 0 |
| -28 dB | 1 | 1 | 3 | 3 | 0 |
| -25 dB | 1 | 3 | 4 | 3 | 0 |
| -22 dB | 1 | 4 | 7 | 9 | 1 |

即使把阈值拉到 -22dB（已经高到会把台词间隙也当静音），全片也只有个位数切点。
BGM 的存在把整个音轨的底噪托起来了，「静音」这个概念在短剧里基本不成立。

**结论：短剧素材必须用 VAD 做主通道，silencedetect 只能作为补充。**

## 三、VAD 切点的构造

`fsmn-vad` 输出语音段 `[(s1,e1), (s2,e2), ...]`。相邻语音段之间的**间隙**就是候选切点：

```
语音:  [---台词A---]  gap  [---台词B---]  gap  [---台词C---]
                          ↑                 ↑
                     说话人换气/句读停顿 = 天然安全切点
```

分类规则（见 `stage2b_vad.py`）：

| 间隙长度 | 等级 | 处理 |
|---|---|---|
| < 0.22s | 丢弃 | 词内停顿，切了会断音 |
| 0.22 - 0.45s | `OK` | 可切，但吸附时往间隙中心偏 |
| ≥ 0.45s | `SAFE` | 极安全，随便切 |
| 间隙 > 6s | 丢弃 | 可能是场景转换，太长了另作分段处理 |

首尾也要给切点：语音段开始之前（`HEAD`）、结束之后（`TAIL`）。

**为什么间隙切点语义上必然安全**：没人说话 → 不存在字头字尾 → 切不吞字。
这比「靠阈值猜静音」在原理上就强一个量级。

## 四、吸附算法

`stage3_edl.py: snap_to_silence()`

```
1. 秒 → 帧量化： frame = round(t × fps)     消灭浮点误差
2. 在 ±window（默认 3.0s）内筛出所有 len ≥ min_len 的间隙
3. 取「区间中心距目标最近」的那个
4. 切点落在间隙中心（不是边缘）
5. 找不到 → snap = FORCED，显式告警，绝不静默通过
```

### 为什么落「中心」而不是「边缘」

间隙 `[s, e]` 里，`s` 附近可能是上一个字的尾音衰减，`e` 附近可能是下一个字的起音。
落中心两侧都留了余量，切出来的片子接起来最自然。

### 为什么留 pad

短剧台词情绪起伏大，尾音常拖长。哪怕落在间隙中心，也建议
`pad = 0.15s` 的余量参数，避免「切得紧」造成的急促感。

### 关键参数

| 参数 | 默认 | 调整方向 |
|---|---|---|
| `search_window` | 3.0s | 吸附不到就调大到 4-5s；太大则切点离预期远 |
| `pad` | 0.15s | 觉得切得太紧就调到 0.25s |
| `min_silence_len` | 0.22s | 不想切碎词内停顿就调到 0.3s |
| `MAX_MERGE_GAP` | 0.45s | SAFE 级的门槛，按语速调整 |

## 五、silencedetect 参数（无 BGM 素材）

| 素材类型 | `noise` | `d` |
|---|---|---|
| 录音棚 / XLR | -45dB | 0.5 |
| 家庭办公 / 短剧（无 BGM） | -32dB | 0.4 |
| 户外 / 嘈杂 | -25dB | 0.5 |
| TTS 配音（数学静音） | -50dB | 0.25 |

**规则**：阈值要比底噪高 5-10dB。`d` 取你愿意切的**最短停顿**，
低于 0.25s 会切掉词间自然间隙，成片听起来像勒索信。

**永远先跑 `--sweep`** 看覆盖率：

```bash
python scripts/stage2_silence.py --work <work> --sweep
```

判读：

| 现象 | 原因 |
|---|---|
| 0 个静音段 | 阈值比底噪还低 → 调高 |
| 静音占比 < 1% | 阈值太低，或素材有 BGM → 转 VAD |
| 静音占比 > 45% | 阈值太高，台词间隙被当静音了 → 调低 |

## 六、防回归

改吸附参数后必查 `edl.csv` 的 `in_snap` / `out_snap` 列：

- 全部 `SILENCE` → 吸附正常
- 出现 `FORCED` → 该处附近无可切间隙，**人工复核这一刀**
- 出现 `FALLBACK` → 吸附后出点 ≤ 入点，已回退未吸附值，需检查
