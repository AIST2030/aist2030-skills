## 二、效果案例（3 个）

### 案例 1 —— 核心能力（讲稿 → 动画成片）

- **场景标题**：写完讲稿就出片，画面自己会跟着念
- **场景描述**：把 27 页 PPT 的备注稿（约 4900 字）交给本技能，直接产出 17 分钟竖版动画解说视频：162 句切成 2514 个词、每个词都有精确时刻，页面元素挂在对应词的发音上入场——旁白念到「第二个」，第二张卡片就在此刻滑入；字幕逐词高亮且**严格单行不跳行**。
- **示例问题**：「把这个 PPT 的备注稿做成会动的解说视频，画面要跟着配音动」
- **触发条件**：用户提供 PPTX 并提到「做成视频 / 讲解视频 / 动画视频 / 备注转视频」。

### 案例 2 —— 典型场景（课程/产品/获客讲解）

- **场景标题**：课程与产品讲解的批量成片产线
- **场景描述**：培训课、产品介绍、获客 SOP 这类内容天然就是「PPT + 讲稿」形态。本技能把讲稿拆到词级后，能自动生成分镜触发表——每个元素挂在哪一句的哪个词上一目了然，改版时只改触发关键词即可调节奏，无需重录。交付的 `timeline.json` 与场景模板代码可跨集复用。
- **示例问题**：「这一系列有 20 节课，每节一个 PPT，能不能做成一模一样的动画风格」
- **触发条件**：用户提到系列课程、批量成片、风格统一。

### 案例 3 —— 边界说明（与静态翻页版二选一）

- **场景标题**：只做「备注 → 动画成片」，不做内容创作，也不是最省的那条路
- **场景描述**：本技能是下游合成环节，不生产 PPT 内容与选题；讲稿必须与 PPT 备注**逐字一致**（脚本内置忠实度硬闸门，不一致直接终止）。若只要「静态截图翻页 + 底部字幕带」的轻量成品、或本机没有 Chrome/Node 运行时，应改用 `aist2030-dev-ppt-narration-video-v2`。另外动画版渲染耗时较长（3 万帧约 80 分钟），追求快速出片时请选静态版。
- **示例问题**：「你能顺便帮我把 PPT 内容也改好吗？」
- **触发条件**：用户询问内容创作、渲染耗时或方案取舍时据此澄清。

## 五、与其他 Skill 的关系（anti-dup 口径）

| 对比对象 | 区分口径 |
|---|---|
| `aist2030-dev-ppt-narration-video-v2` | v2 是**静态截图翻页 + 底部字幕带**（无 Remotion、无词级时间轴、画面不随语音变化）；本技能是**代码驱动、元素跟随语音入场、词级高亮字幕**。按成品形态与预算二选一。 |
| `aist2030-dev-doc2video-v1` | doc2video 面向逐字稿/分镜表的长视频自由创作；本技能专攻「以 PPT 备注为唯一讲稿来源」的解说视频，且带忠实度硬闸门。 |

## 六、上架后经营动作

1. **补货架与个人主页**：把本技能与 v2 静态版并列展示，让买家按预算自行选择档位。
2. **多版本迭代**：后续把「场景模板库」持续扩充（如加图表页、对比页模板），每次迭代写清变更说明，买断用户可下载全部版本。
3. **关注评价与订单**：重点看「渲染耗时」「音色满意度」两类反馈，前者可通过分段渲染优化，后者可扩音色预设。
4. **与课程/获客内容联动**：本技能本身就产课程讲解视频，可作为 AIST2030 课程与 GEO 获客内容的内部产能工具，形成「自用 → 打磨 → 上架」的闭环。
