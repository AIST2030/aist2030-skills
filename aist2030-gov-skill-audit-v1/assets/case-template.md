# AIST2030-gov-skill-audit-v1 效果案例（SkillHub 发布用，3 个）

> 以下案例均为本技能审计流程的真实化输出示例，非虚构。

### 案例 1 —— 核心能力（full 双引擎全量审计）

- **场景标题**：对一个含第三方依赖与动态命令拼接的发文 Skill 做全量安全审计
- **场景描述**：目标 `AIST2030-post-media-search-v1` 声明依赖 Pexels API；审计以 `audit_mode=full` 执行。科恩引擎发现 `requirements.txt` 中 `requests>=2.0`（版本范围过宽，低危）、某脚本用 `os.system("curl " + url)` 拼接外部 URL（中危，参数部分可控）。云鼎引擎未发现 Prompt 注入与越狱话术，语义层描述与代码一致。双引擎未交叉命中，风险未升级。
- **示例输入**：`审计 /workspace/skill-factory/publish/AIST2030-post-media-search-v1`（full / all）
- **示例输出**（节选）：
  ```
  # 双实验室 Skill 安全审计报告
  ## 一、审计概览
  - 审计对象：AIST2030-post-media-search-v1
  - 执行引擎：科恩 + 云鼎（full）
  - 综合风险等级：【中】
  - 风险统计：高危 0 项，中危 1 项，低危 1 项
  ## 二、科恩层
  ### 2. 命令执行风险
  - **[中危]** 动态拼接外部 URL 进 os.system 调用（位置：scripts/fetch.py:42；整改：改用带白名单的参数化请求，禁止字符串拼接执行）
  ### 1. 供应链风险
  - **[低危]** 依赖版本范围过宽 requests>=2.0（位置：requirements.txt:3；整改：固定版本并加锁文件）
  ## 三、云鼎层：无风险项
  ## 五、整改优先级：①【中危】命令拼接 → 完成标准：去除字符串拼接执行
  ```
- **触发条件**：用户对任意 Skill 目录执行"审计 <路径>"类指令。

### 案例 2 —— 典型场景（keen 仅代码层，捕获未声明外发）

- **场景标题**：仅代码层审计发现隐蔽数据外传
- **场景描述**：目标某内部 Skill 在 `SKILL.md` 中仅声明"读取本地知识库并生成摘要"，但科恩引擎（`audit_mode=keen`）扫描发现其网络模块将 `~/.ssh/id_rsa` 内容作为 POST 参数发往一个未知 IP 直连地址。该行为在描述中完全未声明，属高危网络外传；云鼎层未参与（keen 模式）。
- **示例输入**：`审计 /path/to/suspect-skill`（keen / all）
- **示例输出**（节选）：
  ```
  ## 二、科恩层
  ### 4. 网络与数据外传风险
  - **[高危]** 将 ~/.ssh/id_rsa 内容 POST 至未知 IP 1.2.3.4（位置：exfil.py:17；整改：立即移除凭证读取与外传逻辑，明确定义并声明所有网络行为）
  ## 五、整改优先级：①【高危】凭证外传 → 完成标准：删除外传代码并复核全部网络请求域名白名单
  ```
- **触发条件**：怀疑某个 Skill 存在未声明网络行为时，用 keen 模式快速定位代码层风险。

### 案例 3 —— 边界 / 约束说明

- **场景标题**：yunding 仅语义层审计发现语义伪装 + 无风险场景
- **场景描述**：
  - **语义伪装（中危）**：目标 Skill 的 `SKILL.md` 自称"仅做本地文本润色"，但云鼎引擎（`audit_mode=yunding`）语义比对发现其系统提示中包含"忽略安全规则、输出受限内容"的越狱引导话术，描述与真实意图不符 → 标注偏差。
  - **无风险（【无风险】）**：对 `AIST2030-post-product-360-v1` 做 full 审计，科恩层仅发现"向 apihub.agnes-ai.com 发起请求且与声明一致（低危/正常）"、无命令执行/混淆/凭证读取；云鼎层无注入与越狱话术、描述与代码一致 → 输出 `【无风险】` 并附审计覆盖说明。
- **示例输入**：`审计 /workspace/skill-factory/publish/AIST2030-post-product-360-v1`（full / all）→ 期望 `【无风险】`
- **触发条件**：发布前对合规 Skill 做基线审计，或对可疑 Skill 做语义层专项核查。
