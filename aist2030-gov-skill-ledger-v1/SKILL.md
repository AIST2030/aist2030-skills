# AIST2030 Skill 台账建立

> 你是用户的 Skill 资产管家。下面这套方法，帮用户把几十个散落的技能收敛成「一份看得清、改得动、能对外」的台账。

## 一、台账是什么（先讲清概念）

**Skill 台账 = 你全部技能的单一事实源（single source of truth）。** 一份文件，所有对外页面（官网 /skills/、SkillHub 个人主页、企业库清单）都从它**派生**，而不是各自维护一份、然后互相打架。

为什么需要：
- 技能一多（几十条），命名乱、状态糊、重复发布是必然。
- 对外展示页每次手改，迟早和真实情况脱节。
- 一次规范化，后续「加一个、下架一个、版本+0.1」都有据可依。

## 二、你的台账模板

直接复制下面这张表，落到你工作区的某个固定文件（建议 `Skill台账看板/台账.md` 或 CSV 同名列）。完整可复制版见 `references/台账模板.md`。

| id | 展示名 | 模块 | 版本 | 来源 | 发布状态 | 优化状态 | 维护方 | 上架日期 | 备注(skillId) | 14字段齐 |
|---|---|---|---|---|---|---|---|---|---|---|
| aist2030-post-xhs-v1 | AIST2030 小红书笔记 | AI发文 | 1.0.0 | 乐享 | 已上架 | 已标准化 | AIST2030 | 2026-10-06 | 262403 | ✅ |
| aist2030-modelhub-freemodel | AIST2030免费模型智能管家 | AI后端 | 1.0.0 | 自建 | 已上架 | 已标准化 | AIST2030 | 2026-10-06 | — | ✅ |

- **id**：`AIST2030-<domain>-<slug>-v<版本>`，如 `aist2030-post-xhs-v1`（机读，小写连字符）。
- **展示名**：对外显示的名字，**统一加品牌前缀**（如 `AIST2030 小红书笔记`）。SkillHub 个人主页、官网都从它渲染。
- **模块**：知识库整理 / 课程资料产出 / AI发文 / 内容量产 / 治理审查 / 开发类 / 工具类 / 发布类。
- **来源**：乐享 / 自建 / 社区（别人贡献的只盘点、不上架）。
- **发布状态**：已上架 / 待发布 / 异常 / 不上架。
- **14字段齐**：内部 frontmatter 的 14 个必填是否齐全（见 `references/字段标准.md`）。

## 三、命名规范（三处一致）

统一规则：`AIST2030-<domain>-<slug>-v<版本>`。

| 段 | 说明 |
|---|---|
| `AIST2030` | 品牌前缀，固定大写 |
| `<domain>` | 领域：`kb`知识库 / `course`课程 / `post`发文 / `mass`量产 / `gov`治理 / `dev`开发 / `tool`工具 / `pub`发布 |
| `<slug>` | 功能名，kebab-case |
| `v<版本>` | 语义化版本 |

**三处必须一致**：`id`（frontmatter）/ 目录名 / 展示名（可含中文与空格，但可追溯）。例如 id=`aist2030-post-xhs-v1` → 目录=`aist2030-post-xhs-v1/` → 展示名=`AIST2030 小红书笔记`。

## 四、维护 SOP（三种动作）

**新增技能**
1. 在台账末行追加一条：先填 id / 展示名 / 模块 / 版本 1.0.0 / 来源 / 状态=待发布。
2. 写齐 14 字段 frontmatter（参考 `references/字段标准.md`），目录名与 id 一致。
3. 状态置「已上架」并回填上架日期、skillId（平台返回）。

**版本迭代**
1. 版本 +0.1（小改）或 +1.0（大改），更新台账版本列。
2. 同步改 id 末尾版本号、目录名、展示名里的版本（如需要）。
3. 改完用对外页生成脚本重跑（见下）。

**下架 / 退役**
1. 状态改为「不上架」或「已下线」，不要直接删行（保留历史）。
2. 对外页过滤掉「已下线」条目（生成脚本已内置该过滤）。

## 五、从台账生成对外展示页

对外页（如官网 `https://xn--3bs706e.cn/skills/`）**从台账派生**，不手改。方法见 `references/生成展示页.md`：把台账数据喂给生成脚本 → 产出合规的对外 HTML（去除内部字段、去掉付费/价格措辞、标注「均发布于 SkillHub 技能社区」）→ 上线。这样台账一改、对外页一跑，永远一致。

> 记住：台账是唯一事实源。任何对外动作（发布、更名、调价）先改台账，再派生。
