### 字段取值字典
- **模块**：知识库整理 / 课程资料产出 / AI发文 / 内容量产 / 治理审查 / 开发类 / 工具类 / 发布类
- **来源**：乐享 / 自建 / 社区（别人贡献的只盘点、不上架）
- **发布状态**：已上架 / 待发布 / 异常 / 不上架 / 已下线
- **维护方**：AIST2030 / AIOPC / 社区贡献
- **14字段齐**：内部 frontmatter 14 必填（id,name,module,version,owner,role,context,task,format,constraint,quality_gate,anti_dup,input_schema,output_schema）

## 命名规范（三处一致）

```
AIST2030-<domain>-<slug>-v<版本>
```
| 段 | 取值 |
|---|---|
| `AIST2030` | 品牌前缀，固定大写 |
| `<domain>` | kb 知识库 / course 课程 / post 发文 / mass 量产 / gov 治理 / dev 开发 / tool 工具 / pub 发布 |
| `<slug>` | 功能名，kebab-case |
| `v<版本>` | 语义化版本（1.0.0 起，小改 +0.1） |

- id（frontmatter）= `aist2030-post-xhs-v1`
- 目录名 = `aist2030-post-xhs-v1/`
- 展示名 = `AIST2030 小红书笔记`（对外显示，统一带品牌前缀）

## 维护 SOP

**新增**：台账末行追加 → 写齐 14 字段 → 状态=待发布 → 上架后改「已上架」并填日期+skillId。
**迭代**：版本 +0.1 → 同步 id/目录/展示名版本号 → 重跑对外页生成脚本。
**下架**：状态改「已下线」，不删行；对外页脚本已过滤「已下线」。
