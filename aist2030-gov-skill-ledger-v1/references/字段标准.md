# 内部技能标准：14 个必填字段（SKILL_SPEC v2）

> 适用范围：所有 AIOPC 内部技能（无论是否对外发布），由内部门禁强制执行。
> 对外发布到 SkillHub 还需叠加 6 个字段：name / description / tags / version / capability / pricing。

## 元信息字段（YAML frontmatter）

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `id` | ✅ | string | 唯一标识，`AIST2030-<domain>-<slug>-v<版本>`，如 `aist2030-kb-card-v1` |
| `name` | ✅ | string | 技能中文名（展示名，统一带 AIST2030 前缀） |
| `module` | ✅ | enum | 知识库整理 / 课程资料产出 / AI发文 / 内容量产 / 治理审查（或开发类/工具类/发布类） |
| `version` | ✅ | string | 语义化版本，从 v1.0 起，迭代 +0.1 |
| `owner` | ✅ | string | 维护方，默认 `AIOPC` |
| `role` | ✅ | string | 角色设定（RCTFC 的 R） |
| `context` | ✅ | string | 上下文 / 输入物说明（C） |
| `task` | ✅ | string | 任务目标（T） |
| `format` | ✅ | string | 输出格式规范（F） |
| `constraint` | ✅ | string | 约束，含可信度标注要求（C） |
| `quality_gate` | ✅ | list | 发布前自检项（list of string） |
| `anti_dup` | ✅ | string | 防同质化规则 |
| `input_schema` | ✅ | string | 输入物的结构化描述（字段/形态/约束） |
| `output_schema` | ✅ | string | 输出物的结构化描述（可直接作为下游输入） |

**14 个必填**：`id, name, module, version, owner, role, context, task, format, constraint, quality_gate, anti_dup, input_schema, output_schema`。

## 选填字段
- `deps`：依赖的其它技能 id（上游），默认空
- `example_io`：一段「输入 → 输出」范例
- `tags`：检索标签
- `capability`：能力声明（一句话）
- `pricing`：定价/获取方式；内部默认「免费/内部」，对外发布到 SkillHub 时填 `model + amount_fen`
- `displayName` / `slug`：对外展示名 / 机读 slug（slug 只含小写字母、数字、连字符）

## 命名规范（三处一致）
`id` / 目录名 / 展示名 都遵循：`AIST2030-<domain>-<slug>-v<版本>`。
- `<domain>`：kb / course / post / mass / gov / dev / tool / pub
- `<slug>`：kebab-case，机读
- 展示名可含中文与空格，但必须可追溯，且统一带 `AIST2030` 前缀。

## 对外发布叠加项（SkillHub）
- `description`：首句写「**输入：… 输出：… 适用边界：…**」三段式
- `pricing`：`model: free`（免费）或 `per_call`（按次，填 `amount_fen`）；当前政策下对外页一律标注「均发布于 SkillHub 技能社区」
- 资源约束：根目录含 `SKILL.md`、≤10MB、≤200 文件
