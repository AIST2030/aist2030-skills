# 从台账生成对外展示页

> 核心原则：**台账是唯一事实源，对外页从它派生，不手改、不双写。**

## 流程

1. 维护一份台账 CSV（字段见 `台账模板.md`）：`台账.csv`
   - 列：`id,展示名,模块,版本,来源,发布状态,优化状态,维护方,上架日期,备注`
2. 跑生成脚本：`python references/build_ledger_dashboard.py 台账.csv`
3. 产出两份文件：
   - `台账看板.html`：内部全量看板（含 异常/不上架/已下线，供自己盘点）。
   - `技能展示页.html`：对外合规版（自动过滤「已下线」，去除内部字段、去除价格/付费措辞，底部标注「均发布于 SkillHub 技能社区」）。
4. 对外版上线到官网 `/skills/`（或任意静态托管），与台账保持一致。

## 合规要点（对外版自动处理）
- 不暴露内部字段（opt/owner/date/note、skillId 等）。
- 不出现「免费/价格/买断/付费」等可能引发合规风险措辞；统一口径「均发布于 SkillHub 技能社区」。
- 遵守 PRC 广告法：不用「最佳/第一/领先」等绝对化用词。
- 下线技能不进入对外页。

## 与现有工程的衔接
本项目（AIST2030）的对外页由 `_work/build_public_page.py` 从 `Skill台账看板/skill-dashboard.html` 派生；后续统一改成「台账 CSV → 生成脚本 → 对外页」即可彻底消除双写。
