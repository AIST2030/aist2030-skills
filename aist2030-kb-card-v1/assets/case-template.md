# AIST2030 知识卡片整理 效果案例（case-template）

> 提供 3 个效果案例，供发布前核对与下游参考。

### 案例 1（核心场景）：口语录音稿 → 结构化卡片

**输入**
"今天聊到 AI Agent，就是能自己规划步骤去完成任务的 AI……听说 OpenAI 的 Operator 和 Anthropic 的 Claude 都能干这个，不过具体差别我记不清了。"

**预期输出要点**
- 输出卡片表，含 card_id/title/body/category/tags/source/credibility/related
- 来源标"录音稿"，产品对比类 credibility=低并标"待核实"
- 每张卡片单点、可被下游直接引用

### 案例 2（行业变体）：产品发布会网页摘录

**输入**
一篇新品发布长文（含功能点、参数、用户评价）

**预期输出要点**
- 拆为 概念/方法/数据/案例/误区 多类卡片
- 参数类标"中/高"可信度并附原文 URL
- 不同卡片用不同角度（定义/机制/案例/反例）覆盖，避免雷同

### 案例 3（边界场景）：无来源随手笔记

**输入**
"感觉 AI 以后会替代很多岗位吧，说不清为什么。"

**预期输出要点**
- credibility=低，source=待核实
- related 留空
- 不补原文没有的"论据"，严格只记事实
