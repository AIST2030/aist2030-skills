# AIST2030-图片唤醒工具

## 核心原则

1. **用户零门槛**：用户不会描述如何让图片动起来，只需上传图片 + 点选短按钮（2-4字），所有提示词自动生成，不要求用户打字。
2. **商业优先级**：菜单顺序按 group.priority 升序排列（0 兜底 → 1 商品产品 → 2 餐饮菜品 → 3 人像商家应用 → 4 门店外景&风景 → 5 萌宠&IP形象 → 6 动漫插画IP → 7 短剧&电影运镜 → 8 氛围特效）。付费意愿高的商家场景置顶，个人娱乐场景靠后。
3. **品牌统一**：工具名固定为「AIST2030-图片唤醒工具」；所有输出末尾固定追加关注引导 + 免责声明。
4. **多端同源**：本 Skill 的全部动效数据读取自 `references/effects.json`，该文件与 WorkBuddy 知识库内容 100% 同源，禁止在 SKILL.md 内另写一套提示词。
5. **真实运动原则（V1.1 核心）**：每条提示词必须让画面产生真实可见的运动，而非静止加特效。运动三要素，至少包含其一：
   - 镜头运动：推进/拉远/环绕/横移/升降/旋转（最可靠，几乎适用于所有图）
   - 环境元素运动：蒸汽上升、烟雾扩散、花瓣飘落、水流涟漪、光斑游走、火焰跳动
   - 主体微动：呼吸起伏、眨眼、发丝衣摆飘动、物体摇摆
   所有运动均为"缓慢/极慢"幅度，禁止剧烈运动；全局后缀已改为"允许镜头缓慢运动与画面元素自然流动"，不再压制动态。

## 数据资产

所有动效配置（分组、短按钮标签、绑定提示词、全局后缀、负面词、页脚文案）位于 `references/effects.json`。**执行前必须先 Read 该文件**，按其中数据结构渲染菜单与拼接提示词。

数据结构速览：
- `meta`：项目标识、版本、单图/多图说明
- `global.suffix_positive`：全局正向后缀（每条提示词自动追加）
- `global.negative_prompt`：全局负面提示词（固定附加，用户不可见）
- `global.multi_image_suffix`：多图模式额外追加的拼接片段
- `global.footer_guide` / `global.footer_disclaimer`：固定页脚
- `groups[]`：每个分组含 `group_name`、`priority`、`effects[]`（每个 effect 含 `label` 短按钮名 + `prompt` 绑定提示词）

## 执行流程

### Step 1：接收图片，判断模式
- 用户上传 **1 张图片** → 单图模式。
- 用户上传 **≥2 张图片** → 多图模式。主动提示用户确认是否按「产品多角度（正面/侧面/俯视/细节）」使用，用于生成连贯展示视频；若用户只是发了多张无关图片，按单图逐一处理。
- 未上传图片但用户要求生成提示词 → 提示用户先上传图片，同时可先展示动效菜单供预览。

### Step 2：识别图片类型（辅助推荐）
- 结合图片内容判断所属分组（商品/菜品/人像/外景/萌宠/插画等）。
- 在菜单顶部标注推荐分组，例如「📌 根据图片内容，推荐选择【餐饮菜品】组」。

### Step 3：渲染动效菜单
- 按 `priority` 升序输出全部分组，每组展示分组名 + 组内全部短按钮（label 用 `【】` 包裹便于点击）。
- 展示格式示例：
  ```
  【智能唤醒】
  商品产品：高光扫过 质感呼吸 蒸汽升腾 细节推近 光影流转 粒子环绕 镜面涟漪 光晕柔展 慢向平移 薄雾轻笼
  餐饮菜品：蒸汽升腾 火焰轻跃 烟雾漫流 油光流动 气泡上浮 光斑游走 细雨凝珠 慢镜俯推 暖光晕染 香雾萦绕
  ...
  ```
- 提醒用户：直接回复按钮名即可，无需打字描述效果。

### Step 4：用户点选 → 拼接提示词
拼接规则（严格按此顺序，保证多端输出一致）：

```
最终正向提示词 = effect.prompt + "，" + global.suffix_positive
              + (多图模式 ? "，" + global.multi_image_suffix : "")
最终负面提示词 = global.negative_prompt
```

- 单图模式：不加 multi_image_suffix。
- 多图模式：必须加 multi_image_suffix，并在输出前说明「已综合参考 N 张图片」。

### Step 5：输出与引导生成
- 输出拼接完成的最终提示词（正面 + 负面分开两行，便于直接粘贴）。
- 末尾固定输出：
  ```
  ——
  🔔 关注AIST2030，获取教程与最新版本
  免责声明：AI生成内容仅供创意参考，不保证输出效果，请遵守相关法规，禁止生成违规内容，生成风险由使用者自行承担。
  ```
- 若当前环境具备视频生成能力（image_to_video 等），在用户确认后可直接用拼接好的提示词 + 上传图片调用生成；否则提示用户复制到目标工具。

## 注意事项

- 禁止在菜单中跳过任何分组；用户是商家还是个人，仅影响推荐标注，不隐藏分组。
- 禁止修改 effects.json 之外的提示词来源；如需新增/调整动效，先更新 `references/effects.json`，再同步更新 WorkBuddy 知识库对应条目。
- 用户要求「换个说法/改效果」时，优先在 effects.json 中挑选最接近的 effect 做微调，不要凭空创作新提示词而破坏资产统一。
- 多图模式下务必保持产品外观、角度信息一致，负面词保持不变。
