# AIST2030 内容矩阵量产 效果案例（case-template）

> 提供 3 个效果案例，供发布前核对与下游参考。

### 案例 1（核心场景）：AI Agent 落地难题材矩阵

**输入**
选题：AI Agent 落地难 ｜ 模板：公众号深度文(已验证) ｜ N=4 ｜ 角度库=[避坑,拆解,案例,数据] 钩子=[反差,悬念,故事,数据] 案例=[电商客服,简历筛选,日报,代码审查]

**预期输出要点**
- 4 条矩阵，platform/angle/hook_var/case_var/title/diff_check 齐全
- 连续两条 angle/case 不撞车，平台语态匹配
- 每条可下发给对应 post-* 技能落地成文

### 案例 2（行业变体）：效率工具跨平台矩阵

**输入**
选题：AI 提效工具 ｜ 目标覆盖 微博/抖音 短内容语态

**预期输出要点**
- 平台语态切换（微博金句体、抖音口播体）
- 变量池随机抽取且矩阵内零重复开头
- 不临场编造新事实，基于已验证素材

### 案例 3（边界场景）：变量池不足时告警

**输入**
只有 2 个 angle、1 个 case 就要求生成 6 条

**预期输出要点**
- 提示补足 角度库≥3 / 案例池≥5 / 钩子池≥5
- 不强行凑数导致撞车
- diff_check 明确标注重复风险
