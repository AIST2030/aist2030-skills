# AIST2030人物志制作流程

**核心产出：飞书在线PPT（必做）｜ 视频生成（可选，用户明确要求时再做）**

## 一、PPT结构规范（41页标准模板）

| 页码 | 内容 | 版式 |
|---|---|---|
| P1 | 封面：人物肖像 + 名字 | 全屏人物照，底部名字 |
| P2 | 副标题：从XX到XX | 左侧小图+右侧标题 |
| P3-P8 | 引入：四段故事四堂课 | 纯文字列表 |
| P9-P10 | 人物背景介绍 | 文字时间线 |
| P11-P14 | 第一章：案例1+核心数据 | 大数字页+启示页 |
| P15-P18 | 第二章：案例2+核心数据 | 同上 |
| P19-P22 | 第三章：案例3+核心数据 | 同上 |
| P23-P26 | 第四章：案例4+核心数据 | 同上 |
| P27-P32 | 方法论总结：看人三点+习惯三点 | 纯文字 |
| P33-P38 | 给创业者五条清单 | 纯文字 |
| P39 | 结尾：国学金句+总结 | 大字居中 |
| P40-P41 | 转化引导+收尾 | 文字+CTA |

## 二、视觉规范

- 画布：竖版540×720（3:4）
- 主色：深蓝底 rgb(15, 35, 70)
- 强调色：金色 rgb(255, 215, 0)
- 字体：标题微软雅黑，正文思源黑体
- 统一元素：左上角AIST2030金色logo，右下角浅灰AIST2030水印

## 三、备注区写作规范（TTS友好）

### 必须遵守
1. **只用逗号和句号**，禁止顿号、分号、破折号、省略号、引号
2. **数字全部中文读法**：五百万、一千八百万、百分之八百，不要写500万、800%
3. **句子短**：每句15-25字，一口气能念完
4. **称呼固定**："AIST2030 Mr.石"，不要用"老师"
5. **每页3-5句**，对应一页画面时长

### 禁止出现
- 破折号"——"（TTS会卡顿或读出来）
- 顿号"、"（换成逗号）
- 分号"；"（换成句号）
- 阿拉伯数字（除非是英文缩写如AI、A轮）

## 四、事实核查要点

- 投资金额、回报率必须联网核实，标注来源
- 人物生平关键节点（毕业、入职、创业年份）不能错
- 上市公司数据（市值、股价）写"截至XXXX年"，避免过时
- 违禁词/极限词检查：不要用"最""第一""唯一"等绝对化用语（除非是公认事实且有出处）

## 五、发布文案配套（可选）

PPT交付后，如用户需要发布到视频号/抖音/小红书，配套输出：
- **标题**：3选1，带数字钩子+人物+核心结论
- **描述**：3行钩子+核心数据+CTA引导评论
- **标签**：行业词+人物词+方法论词+品牌词

## 六、可选：视频生成流程

仅当用户明确要求"做成视频"时执行，否则只交付PPT。

### Step 1: 导出PPTX
```bash
lark-cli drive +export --token "<slides_id>" --doc-type slides --file-extension pptx --output-dir ./export/
```

### Step 2: 本地渲染截图（竖版3:4无黑边）
```bash
libreoffice --headless --convert-to pdf --outdir ./shots/ ./export/xxx.pptx
pdftoppm -jpeg -r 150 ./shots/xxx.pdf ./shots/page
```
- 产出1125×1500竖版JPG，内容铺满无黑边
- **不要用飞书截图API**，返回横版会变形

### Step 3: TTS生成旁白（固定音色直出）
用 `text_to_audio_plus` 直接生成全部页面，**不要用克隆法**：
- 统一prompt开头：`55岁低沉厚重男性，财经题材讲解风格，普通话标准，语速适中，音量平稳，干净无背景音乐。平稳清晰地说：`
- 每页直接生成，音量语速天然一致
- 页间停顿0.4秒

### Step 4: 音频后处理
```bash
# 去静音 + 轻量归一化
ffmpeg -i raw.wav -af "silenceremove=...,loudnorm=I=-16:TP=-1.5:LRA=11" clean.wav
```

### Step 5: 拼接视频
- 每页片段：静态图 + 该页音频时长 + 0.4s停顿（最后一页不加）
- 输出：720×960竖版3:4，H.264，AAC 128k

## 七、常见坑

| 问题 | 原因 | 解决方案 |
|---|---|---|
| 标题最后一个字掉行 | 飞书和LibreOffice字体宽度不同 | 长标题手动拆两行对称，或缩小字号 |
| 音量时小时大 | 每页单独克隆TTS有差异 | 改用固定音色直出，不克隆 |
| 语音不流畅 | 备注里有破折号/顿号 | 清理所有标点，只用逗号句号 |
| 视频有黑边 | 截图API返回横版 | 导出PPTX本地LibreOffice渲染 |
| 页间太急促 | 没有停顿 | 加0.4秒静音间隔 |

## 八、国学金句库（结尾页用）

根据人物特点选一句贴合的：
- 投资/长期主义：苏轼"博观而约取，厚积而薄发"
- 坚持/逆境：郑板桥"千磨万击还坚劲，任尔东西南北风"
- 识人/用人：《论语》"视其所以，观其所由，察其所安"
- 积累/沉淀：荀子"不积跬步，无以至千里"
- 格局/视野：《诗经》"他山之石，可以攻玉"
