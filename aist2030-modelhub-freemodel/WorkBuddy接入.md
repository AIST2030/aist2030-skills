## 三、控制面板能干嘛（双击 control-panel.html）

- **网关状态灯**：绿色 = 在运行；红色 = 没启动（会提示你双击 start-gateway.bat）
- **Key 管理台**：11 家渠道一排一行，粘贴 Key → 点「保存」→ **立即生效，不用重启网关**；已保存的显示掩码，点「清除」可删
- **测一下能不能对话**：选模型 → 输入内容 → 点「发送测试」，回复直接显示在页面上
- **Key 去哪领**：各平台注册地址和免费额度，点链接直接跳转

Key 只写进本机 `.env` 文件，面板不会把它发到任何其他地方（网关也做了来源校验，别的网页无法通过浏览器动你的 Key）。

## 四、领 Key 并填进去（只领一个智谱就够用）

1. 打开 <https://open.bigmodel.cn>，手机号注册（不绑卡）
2. 控制台 → API Keys → 创建密钥，复制那串 Key
3. 回到控制面板 `control-panel.html`，找到「Key 管理台」里的**智谱 BigModel** 一行
4. 把 Key 粘进输入框，点**保存**——按钮变绿「已保存」，渠道状态立刻变「就绪」
5. 完事。**不用重启网关、不用编辑任何文件**

想多填几家就照样子每家粘一遍（硅基流动、DeepSeek 等同理）。

## 六、两条重要提醒

1. **干活必须用「免费GLM-4.7-Flash」**：`auto` 池可能路由到不支持工具调用的小模型（如 Qwen3-8B），那样 Agent 的读写文件/跑命令能力会残废。纯聊天才用 auto。
2. **敏感数据别走免费渠道**：免费层数据可能被平台用于改进产品。涉及客户资料、密码、商业机密的活用你原有的 GLM-5.2（付费订阅）。
