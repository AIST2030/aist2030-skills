# libai-sc1 搜图技能

## 权限白名单（强制）
- **仅允许访问 `cc0.cn` 及其同站图片 CDN `img.cc0.cn`**（取图直链所在域，属同站资源，非外链跳转）。
- **严禁访问任何其他网址，严禁跳转外链。** 脚本内置 `allow()` 域名白名单，任何越权 URL 直接拒绝、跳过，绝不请求。

## 运行规则
1. 接收文案后先理解整句语义，提炼 **3–8 个核心中文关键词**，不直接用长句搜索。
2. 每次正式打开网页前，**强制随机停顿 1–3 秒**，模拟真人浏览，禁止机器连续请求。
3. 仅用站内搜索框（`POST /e/search/index.php`）检索关键词，**不打开网站任何推荐/分类页面**。
4. 图片强制过滤：仅保留**室外实景实拍照片**；自动屏蔽插画、海报、3D 图、抽象艺术、恐怖、畸形、血腥、不适画面、人物大头特写；不符合标准直接放弃该图。
5. 在搜索结果里，只挑选与关键词**匹配度最高的第一张高清原图**，仅提取图片直链。
6. 仅返回图片地址；不校验网站服务器时区，全部以**本机北京时间**为准（脚本不依赖任何服务器时间字段）。
7. 网站打不开、访问受限、无合格图片时，直接返回 **【执行失败】**，**不反复刷新重试**。
8. 不修改、不下载（落盘）图片，仅输出原图链接。为执行规则 4 的过滤，仅在**内存中读取图像字节做合规校验，绝不落盘或篡改**，校验后丢弃，最终只输出原图直链。

## 工作流程
1. 若收到长文案：执行 `libai_sc1.py --text "..."` 自动提炼关键词（jieba TextRank）；也可直接 `--keywords "购物,手机,网络"` 传入已提炼关键词。
2. 对每个关键词：随机停顿 → `POST` 站内搜索 → 取结果前若干张详情页 → 进详情页取第一张图直链 → 内存过滤（尺寸/格式/人脸大头特写）→ 第一张合格即返回。
3. 输出：仅一行图片直链；全程无合格图则输出 **【执行失败】**。

## 参数
| 参数 | 说明 |
|------|------|
| `--text` | 口播/文案内容，自动提炼 3–8 关键词 |
| `--keywords` | 已提炼的逗号分隔关键词（优先于 --text） |
| `--topk` | 提炼关键词数量，默认 5 |

## 实现要点（供排错）
- **白名单**：`allow()` 校验所有请求 URL，越权即跳过。
- **搜索**：帝国 CMS 搜索必须用 `POST`（GET 会被判无效跳转到提示页）；表单字段已硬编码（`tempid=1&show=title&tbname=news`），避免访问首页推荐页。
- **取图**：详情页图片在 `//img.cc0.cn/...` CDN，补全 `https:` 即得原图直链。
- **过滤**：程序自动实现——尺寸≥600px、格式 jpg/png、人脸占比>30% 判定为「人物大头特写」并屏蔽（opencv Haar）。「室外实景 vs 插画/3D/抽象」需更强视觉模型，当前以 cc0.cn 来源（多为实拍）+ 关键词兜底，NSFW 可由模型进一步增强（见脚本注释）。
- **时区**：脚本不读取任何服务器时间，符合规则 6。

## 注意事项
- 仅 cc0.cn 白名单；违规站绝不访问。
- 失败即返回【执行失败】，不重试。
- 过滤为「内存读取、不落盘」，最终仅输出原图链接。
