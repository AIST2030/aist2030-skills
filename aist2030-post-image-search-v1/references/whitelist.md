# 白名单站点参考（搜图技能内置）

> 本文件随 `AIST2030-post-image-search-v1` 一起分发，记录三站搜索 URL 模板、可达性与直链形态。
> 仅在白名单三域内操作；禁止任何站外/外跳。搜索 URL 模板如站点改版，以站点实际站内搜索框行为为准。

## 白名单（硬约束）

| # | 站点 | 域名 | 用途 |
|---|---|---|---|
| 1 | Pixabay 中文站 | `pixabay.com/zh/` | 免费可商用图片（CC0 / Pixabay License） |
| 2 | CC零（cc0.cn） | `cc0.cn/image/` | 聚合 Pixabay 等免费可商用图 |

## 各站搜索 URL 模板与可达性（实测）

### 1) Pixabay 中文站 ✅ 可达、可出图
- 站内搜索 URL：`https://pixabay.com/zh/images/search/<关键词>/`（关键词用 UTF-8，可中文）
  - 示例：`https://pixabay.com/zh/images/search/%E5%92%96%E5%95%A1/`（咖啡）
- 结果页含图片条目，直链形态：
  - `https://pixabay.com/get/g<哈希串>_1920.jpg`（可换尺寸后缀 `_1280.jpg` / `_640.jpg`）
- 备注：WebFetch 直连可出结果；如需更稳可用浏览器自动化点站内搜索框。

### 2) CC零（cc0.cn）⚠️ 首页可达、搜索为 JS 客户端
- 首页：`https://cc0.cn/image/`（可达，展示图片流）
- 静态搜索探测结果：`?q=<词>` 仍返回首页、`/search?q=` 返回 404 → **无静态搜索 URL**，搜索由前端 JS 触发。
- 建议：用浏览器自动化打开 `https://cc0.cn/image/`，在站内搜索框输入关键词并提交；或进入图片详情页 `https://cc0.cn/image/<id>.html` 取原图。
- 直链：详情页内取实际图片文件 URL（图源多为 Pixabay CDN 代理）。
- 备注：若 WebFetch 拿不到过滤后结果，按规则 7 切下一白名单。

### 3) 爱给设计图（aigei）⚠️ 触发验证码（bot 防护）
- 频道：`https://www.aigei.com/design/img/`
- 实测：WebFetch 直连被「验证码拦截」页面拦住（无有效内容）。
- 建议：用浏览器自动化尝试（可能仍需人工验证）；若持续被拦，按规则 7 切下一白名单，不反复刷新。
- 备注：aigei 为注册/会员素材站，免费图有限且带防护，本技能仅在其可达时取免费可商用原图。

## 白名单循环顺序
`1 (Pixabay) → 2 (cc0) → 3 (aigei) → 1 (Pixabay) …`

每站访问前 `sleep(random 1–3s)`；某站打不开/受限/无合格图 → 切下一站；三站皆不行 → 返回 `【执行失败】`。

## 过滤类目（与 SKILL.md 一致）
- 匹配类目：人物、自然风光、植物、动物、交通工具、家居生活、建筑、宇宙航天、体育竞技、食品餐饮、电子数码、节日庆典、学习办公、网络科技。
- 自动屏蔽：插画、海报、3D 图、抽象艺术、恐怖、畸形、血腥、不适画面、人物大头特写。

## 选取规则
- 优先横版；匹配度最高的计第 1，取**第 2 张**高清原图。
- 多场景各取；关键词重复取不同图。
- 只输出最终图片文件直链，不输出页面/详情页 URL。
