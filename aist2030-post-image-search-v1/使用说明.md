# AIST2030 配图检索 · 使用说明

> **技能 ID**：`AIST2030-post-image-search-v1`<br>**作者**：公众号：AIST2023<br>**定位**：发文前的**合规搜图门禁**——只在白名单三站内用站内搜索框找免费可商用高清配图，强制过滤不适内容，真人化节流，只回原图直链。<br>**标准**：遵循 AIOPC 统一命名（AIST2030 品牌）与 SKILL 规格 v2（RCTFC + 自动门禁）。

## 1. 它能做什么
把一段文案变成「图片直链列表」或「【执行失败】」。专为公众号/小红书/知乎等发文配图设计，保证：
- **只走白名单三站**（Pixabay 中文 / cc0.cn / aigei 设计图），不碰任何站外；
- **合规过滤**：屏蔽插画/海报/3D/抽象/恐怖/畸形/血腥/不适/人物大头特写；
- **真人化节流**：每次访问前随机停顿 1–3 秒，禁止机器连续请求；
- **稳定取图**：优先横版，取匹配度第 2 张高清原图；
- **不改不存**：只输出原图链接，不下载、不修改。

## 2. 如何触发 / 调用
- **用户级（所有项目通用）**：技能已安装于 `~/.workbuddy/skills/AIST2030-post-image-search-v1/`（`SKILL.md`+`references/whitelist.md`），Agent 加载后按正文指令执行。
- **工厂集成**：已在 `skill-factory/` 的 `drafts/`（源）、`skills/`（标准件）、`registry.json`（第 11 号）中，通过内部门禁。
- 调用方式：把待配图文案交给该技能即可，例如「给这段公众号文案配图：<文案>」。

## 3. 输入 / 输出
- **输入**：一段待配图的文案（可含多场景/多段落）；可选：期望张数、是否强制横版、风格偏好。
- **输出（成功）**：纯文本，每行一个图片直链；可选头部一行北京时间标注。
  ```
  配图检索 @2026-07-18 18:34 (Asia/Shanghai)
  https://pixabay.com/get/g<哈希>_1920.jpg
  https://pixabay.com/get/g<哈希>_1920.jpg
  ```
- **输出（全失败）**：单行 `【执行失败】`（三站皆不可用时，不反复刷新）。

## 4. 八条运行规则（速查）
1. 理解语义 → 每场景提炼 **3–5 个中文核心关键词**（禁长句直搜）。
2. 白名单 **1→2→3→1** 循环；每次访问前 **随机停顿 1–3 秒**。
3. 只用 **站内搜索框** 检索，不打开推荐页。
4. **强制过滤**：匹配类目取图，屏蔽插画/海报/3D/抽象/恐怖/畸形/血腥/不适/大头特写。
5. 优先横版；取匹配度 **第 2 张** 高清原图；关键词重复取不同图；只提取直链。
6. 只回图片地址；时区统一 **本机北京时间（Asia/Shanghai）**。
7. 站点打不开/受限/无合格图 → **切下一白名单**；三站皆败 → **【执行失败】**，不反复刷新。
8. **不改不存只出链**。

## 5. 白名单与可达性（实测）

| # | 站点 | 搜索 URL / 入口 | 本沙箱实测 |
|---|---|---|---|
| 1 | Pixabay 中文 | `https://pixabay.com/zh/images/search/<关键词>/` | ✅ 可达、出图；直链 `https://pixabay.com/get/g<hash>_1920.jpg` |
| 2 | cc0.cn | `https://cc0.cn/image/`（首页可达；搜索为 JS 客户端，`?q=`无效） | ⚠️ 需浏览器点搜索框；直连无过滤结果 → 按规则7切换 |
| 3 | aigei 设计图 | `https://www.aigei.com/design/img/` | ⚠️ 验证码拦截（bot 防护）→ 按规则7切换 |

> 三站均只提供免费可商用素材（Pixabay License / CC0）。凡触发拦截/无结果即切换，不卡死。

## 6. 过滤类目
- **匹配类目**（与文案语义相符才取）：人物、自然风光、植物、动物、交通工具、家居生活、建筑、宇宙航天、体育竞技、食品餐饮、电子数码、节日庆典、学习办公、网络科技。
- **自动屏蔽**（命中即弃图）：插画、海报、3D 图、抽象艺术、恐怖、畸形、血腥、不适画面、人物大头特写。

## 7. 跑通示例（真实记录）
样例文案：「城市清晨，上班族挤进地铁，手里一杯热咖啡；午后的绿植角，阳光穿过叶片。」
- 场景A 关键词：地铁通勤 / 热咖啡 / 上班族 / 城市清晨
- 场景B 关键词：绿植 / 阳光 / 叶片 / 室内植物
- 实访：①Pixabay ✅ → ②cc0 ⚠️首页无过滤 → ③aigei ⚠️验证码 → 回①Pixabay ✅
- 输出（节选）：

## 8. 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| cc0 搜不到图 | 搜索为前端 JS，静态 `?q=` 无效 | 用浏览器自动化点站内搜索框；否则规则7切下一站 |
| aigei 验证码 | 站点 bot 防护 | 浏览器尝试；仍拦则规则7切换 |
| 全站失败 | 网络/授权受限 | 返回【执行失败】，不反复刷新 |
| 取到竖图 | 结果无横版 | 规则5：无横版再退竖版 |
