# AIST2030 媒体检索（API 图+视频） 效果案例（case-template）

> 提供 3 个效果案例，供发布前核对与下游参考。

### 案例 1（核心场景）：图文公众号配图

**输入**
文案："春季通勤穿搭分享，3 套不踩雷搭配" ｜ media_type=image

**预期输出要点**
- 仅调白名单 Pexels API，提炼 3-5 个中文核心关键词（如 春季/通勤/穿搭）
- 默认只回横版第 2 个相关度最高的免费可商用图片直链
- 严格过滤不适/水印内容，输出直链列表

### 案例 2（视频 + 静音交付）：混剪素材

**输入**
文案："新品发布会 60 秒混剪" ｜ media_type=video ｜ mute=true

**预期输出要点**
- 检索视频直链后，按上游 mute 指令下载并用 ffmpeg 静音
- 交付本地静音 mp4（静音成品层），可直接用于混剪/配口播
- 仍只在白名单域操作，key 走环境变量

### 案例 3（边界场景）：无 key / 无结果

**输入**
未配置 PEXELS_API_KEY，或关键词无匹配

**预期输出要点**
- 不编造直链、不访问站外
- 明确输出【执行失败】并说明原因（缺 key / 无结果）
- 提示上游补关键词或检查环境
