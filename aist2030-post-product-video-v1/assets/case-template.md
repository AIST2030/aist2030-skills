# AIST2030 产品视频生成（文心+千帆） 效果案例（case-template）

> 提供 3 个效果案例，供发布前核对与下游参考。

### 案例 1（核心场景）：拖图生成产品视频

**输入**
触发："生成一个旋转展示的泸州传奇视频" ｜ 用户拖入 1-5 张产品图

**预期输出要点**
- 解析 camera_move=旋转展示 + product_name=泸州传奇
- 优先用拖入图，文心 ERNIE X1 从 20 种运镜中推理选最佳，写中文商业分镜 prompt
- 走千帆 qianfan-video-latest 出 8s/1080P 视频直链 + 封面

### 案例 2（行业变体）：知识库取素材

**输入**
触发："生成一个特写的高光口红视频" ｜ 无拖图（从知识库取产品图）

**预期输出要点**
- 缺拖图时从产品知识库取首帧图（乐享/IMA 白名单）
- 千帆 img2video 仅接受 1 张首帧，其余运镜由 prompt 驱动
- 输出视频直链 + 封面，合规仅在白名单域

### 案例 3（边界场景）：缺产品名且无图

**输入**
触发："生成一个酷炫的产品视频"（无 product_name，无拖图）

**预期输出要点**
- 不擅自编造产品名/图
- 输出【执行失败】并提示补产品名或拖入产品图
- 不调用出片接口，避免空跑
