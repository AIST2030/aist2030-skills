# AIST2030 头条草稿箱批量发布 · 使用说明

> 仅操作你本人草稿箱中**已存在**的文章（不生成新内容），按 8 个高峰时段配额（3/2/3/2/4/5/6/4，共 29 条）自动发布，每次间隔 ≥15 分钟。首次人工登录后日常零介入。

## 一、部署前准备
1. 一台能正常访问 `mp.toutiao.com` 的机器（mp.toutiao.com 在沙箱可解析且可达，但真站登录态/发布仍建议在你本机完成；沙箱可做 `dry-run` 只读校准）。
2. 安装 Python 3.11 + Playwright + 系统 Chromium：
   ```bash
   pip install -r requirements.txt
   playwright install chromium   # 若系统已装 google-chrome 则无需此步
   which google-chrome           # 确认存在
   ```
3. 草稿箱已备好若干待发文章（建议 ≥29 篇以跑满单日配额）。

## 二、准备登录态（二选一）
- **方式 A · 扫码登录**：
  ```bash
  python3.11 scripts/cli.py login
  ```
  浏览器弹出后扫码/凭证登录，登录成功回到终端按回车，`auth.json` 自动保存（权限 600，**切勿提交 git**）。
- **方式 B · Cookie 登录**（你给 cookie 时更顺手）：
  1. 浏览器登录 `mp.toutiao.com` 并打开草稿箱；按 F12 → Application → Cookies → 选中 `mp.toutiao.com` → 复制为 **JSON 数组**（或装 EditThisCookie 一键导出；也可从控制台 `document.cookie` 复制 `name=value;...` 文本）。
  2. 存为 `cookies.json`，执行：
     ```bash
     python3.11 scripts/cli.py import-cookies cookies.json
     ```
     `import-cookies` 支持三种格式：JSON 数组 / 含 `"cookies"` 键的 dict / `document.cookie` 文本；写出 `auth.json`（权限 600）。可选 `--domain .mp.toutiao.com`、`--auth 自定义路径`。

## 二之一、只读预览（强烈建议先跑）
```bash
python3.11 scripts/cli.py dry-run
```
真实进入草稿箱、按发布顺序列出候选队列（首条未标记），**绝不点发布**。据此确认选区与去重逻辑正确，再正式发布。

## 三、日常发布（两种方式任选）
- **方式 A · cron（推荐）**：每日由系统定时拉起，进程因间隔 sleep 全天存活，末次发布后退出，次日重拉。
  - Linux/mac：`crontab scheduler/crontab.linux.txt`（每日 07:55）
  - Windows：管理员 PowerShell 导入 `scheduler/task-scheduler.xml`
- **方式 B · 常驻**：无 cron 环境用 nohup 常驻，自带日循环。
  ```bash
  nohup python3.11 scripts/cli.py run-forever > run.log 2>&1 &
  ```

## 四、监控与对账
```bash
cat state.json     # published 列表 + paused 标志
cat notify.log     # 异常暂停通知
tail -f run.log    # 实时运行日志
```
- 想续跑中断的任务：清除 `state.json` 里的 `paused` 标志后重跑 `run-day` 即可（已发布自动跳过）。
- 登录态过期：重新执行 `login` 刷新 `auth.json`。

## 五、开发期冒烟（不触真站）
```bash
python3.11 scripts/cli.py mock-smoke --fail-first 0   # 全成功：29 条去重/状态写回
python3.11 scripts/cli.py mock-smoke --fail-first 2   # 每条第3次成功：验证重试可恢复
python3.11 scripts/cli.py mock-smoke --fail-first 9   # 首条耗尽重试：验证暂停+notify.log
```
> 真站只读校准：若你授权在沙箱用 cookie，可 `import-cookies` 后 `dry-run` 进入真实草稿箱列出候选队列（绝不发布）。

## 六、安全与合规
- **只读**：对标题/封面/正文只读取定位、零写入，仅点击「立即发布」。
- **去重**：以本地 `state.published` 为准，已发布永不二次点击。
- **凭证安全**：`auth.json` 含登录态，本地权限 600、不入 git、不进发布包。
- **外部调用仅限 `mp.toutiao.com`**，无数据外传。
- 平台 ToS / 反爬：自动化发布属你本人草稿；建议先小批量试跑观察。
