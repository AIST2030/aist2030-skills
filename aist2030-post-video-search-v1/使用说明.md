# AIST2030 视频检索 · 使用说明

> **技能 ID**：`AIST2030-post-video-search-v1`<br>**作者**：公众号：AIST2023<br>**定位**：发文配视频 + 视频剪辑素材供应的**合规搜视频门禁**——只在白名单两站内用站内搜索框找免费可商用视频，浏览器读真实宽高判横屏、分辨率≥720、取第2个，下载后用 ffmpeg 静音，原素材与静音成品分目录。<br>**标准**：遵循 AIOPC 统一命名（AIST2030 品牌）与 SKILL 规格 v2（RCTFC + 自动门禁）。<br>**与搜图技能的三大差异**：① 视频须**下载 + ffmpeg 静音**（已授权突破"不下载"）；② 横屏靠**浏览器/ffprobe 读真实宽高**判定（Pixabay 静态页不标方向）；③ Mixkit 须**浏览器抓带 referer 的真实下载地址**（WebFetch+猜 CDN 会 403）。

## 它能做什么
把一段文案变成「静音视频本地路径列表 + 来源 URL」或「【执行失败】」。覆盖两大场景——
- **发文配视频**：公众号/小红书/知乎等文章配视频；
- **视频剪辑素材**：素材混剪配播客和口播音频（静音 mp4 直接拖入剪辑轨叠加音频轨）。
保证：
- **只走白名单两站**（Pixabay 视频 / Mixkit），不碰任何站外；
- **合规过滤**：屏蔽宣传广告、带 logo/水印、抽象艺术、恐怖、畸形、血腥、不适、人物大头特写；
- **真人化节流**：每次访问前随机停顿 1–3 秒，禁止机器连续请求；
- **稳定取视频**：优先横屏、分辨率≥720、取匹配度第2个；
- **真静音**：下载后 ffmpeg 剥离音轨（不重编码），原素材与静音成品分目录。

## 如何触发 / 调用
- **用户级（所有项目通用）**：技能已安装于 `~/.workbuddy/skills/AIST2030-post-video-search-v1/`（`SKILL.md`+`references/whitelist.md`），Agent 加载后按正文指令执行。
- **工厂集成**：已在 `skill-factory/` 的 `drafts/`（源）、`skills/`（标准件）、`registry.json`（第 12 号）中，通过内部门禁。
- 调用方式：把待配视频文案交给该技能即可，例如「给这段公众号文案配视频：<文案>」。

## 输入 / 输出
- **输入**：一段待配视频的文案（可含多场景/多段落）；可选：期望数量、是否强制横屏、分辨率下限、输出根目录。
- **输出（成功）**：纯文本，每行一个静音成品的本地路径（`cache/muted/` 下），其后可附来源 URL；可选头部一行北京时间标注。
  ```
  视频检索 @2026-07-18 22:45 (Asia/Shanghai)
  /abs/path/cache/muted/coffee_02.mp4  (来源: https://cdn.pixabay.com/video/2019/09/25/27230-362518559_large.mp4)
  /abs/path/cache/muted/green_02.mp4  (来源: https://cdn.pixabay.com/video/2023/02/25/152111-802335550_large.mp4)
  ```
- **输出（全失败）**：单行 `【执行失败】`（两站皆不可用时，不反复刷新）。

## 八条运行规则（速查）
1. 理解语义 → 每场景提炼 **3–5 个中文核心关键词**（中文优先，识别不出可英文）；禁长句直搜。
2. 白名单 **1→2→1** 循环；每次访问前 **随机停顿 1–3 秒**。
3. 只用 **站内搜索框** 检索，不打开推荐页。
4. **强制过滤**：匹配类目取视频，屏蔽宣传广告、带 logo/水印、抽象艺术、恐怖、畸形、血腥、不适、人物大头特写。
5. **横屏 + 第2个 + ≥720**：浏览器/ffprobe 读真实宽高，优先横屏（width>height）；取匹配度第2个；分辨率≥720；关键词重复取不同视频；只提取直链/下载地址。
6. 只回视频地址；时区统一 **本机北京时间（Asia/Shanghai）**。
7. 站点打不开/受限/无合格视频 → **切下一白名单**；两站皆败 → **【执行失败】**，不反复刷新。
8. **静音下载分支**：默认下载原视频到 `cache/raw/`，ffmpeg 剥离音轨存 `cache/muted/`（原素材与成品分目录）；无 ffmpeg/无下载权 → 回退只出原视频直链并标注"未静音"。

## 白名单与可达性（实测）

| # | 站点 | 搜索入口 | 本沙箱实测 |
|---|---|---|---|
| 1 | Pixabay 视频 | `https://pixabay.com/zh/videos/search/<关键词>/` | ✅ 静态/浏览器可见；直链 `cdn.pixabay.com/video/.../_large.mp4`；CDN 开放可下载 |
| 2 | Mixkit | `https://mixkit.co/free-stock-video/`（站内搜索框） | ✅ 可达、可搜索；直链须浏览器抓带 referer 的真实地址（猜 CDN 返 403）；详情页显式提供 1080x720/1920x1080/4K |

> 两站均只提供免费可商用素材（Pixabay License / Mixkit 免费无水印）。凡触发拦截/无结果即切换，不卡死。

## 过滤类目
- **匹配类目**：人物、自然风光、植物、动物、交通工具、家居生活、建筑、宇宙航天、体育竞技、食品餐饮、电子数码、节日庆典、学习办公、网络科技。
- **自动屏蔽**：宣传广告、带 logo 或水印的视频、抽象艺术、恐怖、畸形、血腥、不适画面、人物大头特写。

## 静音下载文件夹策略（关键）
- `cache/raw/`：下载的**原素材**（带原始音轨），供后续删除，**不作为交付物**。
- `cache/muted/`：**静音成品**（ffmpeg 剥离音轨），**唯一交付物目录**。
- 静音命令（不重编码，秒级）：`ffmpeg -i <raw.mp4> -an -c:v copy <cache/muted/xxx.mp4>`
- 若无法静音（无 ffmpeg / 无下载权）：回退只出原视频直链，标注"未静音"。

## 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| Mixkit 直链 403 | 猜的 CDN URL 无 referer | 用浏览器抓带 referer 的真实下载地址；不要猜 `assets.mixkit.co/...mp4` |
| Pixabay 只给 5KB 空壳 | curl 拿到 JS 壳 | 用浏览器渲染（或 WebFetch）取渲染后直链 |
| 取到竖屏/小视频 | 未读真实宽高 | 浏览器/ffprobe 读 width/height，width>height 且 height≥720 才取 |
| 静音失败 | 无 ffmpeg | 回退只出原视频直链并标注"未静音" |
| 全站失败 | 网络/授权受限 | 返回【执行失败】，不反复刷新 |
