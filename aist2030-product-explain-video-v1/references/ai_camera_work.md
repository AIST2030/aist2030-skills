# 阶段 2 · AI 运镜（转盘旋转 / 细节推进 / AI 人物手托）

> 用户图经过 [product_recognition.md](product_recognition.md) 识别成 3D 档案后，
> 本阶段把「镜头语言」变成**真的会动的视频片段**（mp4），而不是对静态图做推拉。

## 0. 三种核心 AI 运镜与对应引擎

| 运镜类型 | 视觉目标 | 首选引擎（需 Key） | 本地兜底（无 Key） |
|---|---|---|---|
| **转盘旋转** turntable | 产品绕中轴自转，展示全貌 | `product-360`（Agnes，2–3 张多角度图→360°视频，免费额度） | 多图 + 深度估计做「视差转盘」拟态（见 §4） |
| **细节推进** detail_push | 镜头推近某特征并聚焦（logo/屏幕/接口/纹理） | `product-video`（千帆，图→8s 运镜特写，需 Key）/ `image-awake`（图→动效提示词→图生视频） | 深度感知 Ken Burns（scale + blur 背景 + 焦点位移，见 §4） |
| **AI 人物手托** hand_hold | 一只手托着/握着产品做英雄展示 | 角色视频模型（图+提示词→带人物视频，如 LongCat-Video / 即梦 / 可灵 类）；或数字人 `Avatar Forge`/`InfiniteTalk` 合成口播+产品同框 | 产品悬浮 + 光影 + 粒子（不出现真人手，见 §4 兜底 B） |

优先级：**转盘（建立全貌）→ 细节（讲卖点）→ 人物手托（拟人化信任）**。
不是每段都要三种；按 `shot_plan` 的 feasible 决定，缺图/缺 Key 自动降级不卡流程。

## 1. 转盘旋转 · product-360 (Agnes)

**契约**（详见 `aist2030-post-product-360-v1` SKILL）：
- 输入：2–3 张不同角度产品图（front/side/back 最佳）。
- 输出：360° 环绕视频（mp4），免费 API 额度。
- 关键参数：转角度数（识别缺角度时减半，避免露白面）、背景（透明/纯色便于合成）、分辨率。
- 失败/无 Key → 走 §4 本地视差转盘。

## 2. 细节推进 · product-video (千帆) / image-awake

**product-video（千帆）契约**（详见 `aist2030-post-product-video-v1` SKILL）：
- 输入：单张产品图 + 运镜短语（来自 camera-prompt，如 `push-in on logo, macro`）。
- 输出：8s / 1080P 运镜特写 mp4。
- 需 `QIANFAN_API_KEY`。

**image-awake 契约**（详见 `aist2030-mass-image-awake-v1` SKILL）：
- 输入：产品图（可多张）。
- 输出：图生视频的动效提示词 / 直接出片，适合「材质流动、光泽扫过、轻微浮动」类细节感。

无 Key 时：用 §4 深度感知 Ken Burns，把单图做出「推近+焦点位移」的伪运镜，观感接近但非真 3D。

## 3. AI 人物手托 · 角色视频模型 / 数字人

目标：一只手自然托住产品，配合英雄光，强化「真实可用、有人在用」的信任感。

- **角色视频模型**（图+文本→视频）：给产品图 + 提示词
  `"a hand gently holding the [product], studio light, slow turntable, hero shot"`，
  选支持图像参考的模型（LongCat-Video / 即梦 / 可灵 等）。需对应 Key。
- **数字人同框**：`Avatar Forge` / `InfiniteTalk` 让数字人手持产品口播，
  适合「数字人讲解」形态（见 `voice_presets.md`）。
- **无 Key 兜底**：见 §4 兜底 B（产品悬浮 + 光影 + 粒子，不出真人手）。

> ⚠️ 安全与合规：AI 生成人物须避免伪造特定真实人物、名人肖像；
> 手托展示用「通用手/数字人」即可，不要指向具体真人。

## 4. 本地兜底（无 Key / 模型不可达时仍可出片）

### 兜底 A · 深度视差转盘（替代 product-360）
对 2 张图（front + side）做单应/深度估计，生成左右视差序列，
在 ffmpeg 里以小幅 `zoompan + 水平位移 + 轻微旋转` 模拟「绕转」，
配合背景模糊与边缘羽化，弱化「平面」感。限制：只能做小幅（±15°）转盘。

### 兜底 B · 产品悬浮 + 光影 + 粒子（替代 AI 人物手托）
不出现真人手，而是：
- 产品居中，**投影 + 地面反光**做出「悬浮」体积感；
- 一束 hero 光从左上扫过（CSS/ffmpeg `curves`/遮罩动画）；
- 少量金色粒子上浮（libass 或 overlay 序列）；
- 配文字动效「托起你的生意」类金句（见 `typographic_motion.md`）。
观感接近「被珍视地展示」，且 100% 本地、零 Key、零合规风险。

## 5. 质检门槛（每段 AI 运镜片段交付前）

- [ ] 分辨率 ≥ 输出画幅（横版 1920×1080 / 竖版 1080×1920），不足则升采样但不强行拉伸变形。
- [ ] 时长与 `口播时间轴.json` 对应段落匹配（±0.3s）。
- [ ] 转盘无穿帮（不露白面、不露拍摄桌）；细节推进焦点清晰；人物手托不遮挡核心卖点。
- [ ] 背景为纯色/透明或已做模糊，便于在 [composite_runbook.md](composite_runbook.md) 里合成。
- [ ] 无 Key 兜底片段须打 `flag: local_sim`，成片验收时告知用户「此段为本地拟态」。
