# 广告法合规自检（PRC）

> 用户强调过：文案须遵守 PRC 广告法，规避绝对化用词，禁止"免费/价格"硬推。本文件为强制自检关卡。

## 一、禁用绝对化用词（命中即改写）

| 类别 | 禁用词示例 |
|---|---|
| 最高级 | 最、最佳、最强、最优、顶级、极致、绝无仅有、史无前例 |
| 第一 | 第一、NO.1、销量第一、排名第一、领导品牌（无佐证） |
| 唯一 | 唯一、独家、仅此一家、绝无仅有 |
| 领先 | 领先、遥遥领先、行业领先（无数据） |
| 革命 | 革命性、颠覆性、划时代 |
| 绝对 | 绝对、百分百、guaranteed、必购、必备 |
| 虚假承诺 | 包治、速效、立马见效、零风险、100%有效 |

## 二、改写示例

| 原文 | 改写 |
|---|---|
| 行业最佳白酒 | 深受宴席青睐的白酒 |
| 领先技术 | 成熟的酿造工艺 |
| 唯一选择 | 值得考虑的选择 |
| 绝对纯粮 | 选用纯粮酿造 |

## 三、自检规则（每次生成文案后必跑）

1. 扫描文案是否含上表禁用词 → 有则改写并标注「已合规改写」
2. 涉及数据/排名/认证 → 须有依据，无依据删除或加「据XX」来源
3. 不使用「免费」「价格」做硬推（用户规定）
4. 医疗/功效类宣称（如护肤「美白」）→ 需有备案/检测，否则删除
5. 全程无「国家级」「最高级」「最佳」等《广告法》第九条明令禁用语

## 四、输出要求
- 成片前由 compliance 复检，结论写入交付头部「合规：通过/已改写 N 处」
- 任一未处理禁用词 → 阻塞交付，回改写后再出片
