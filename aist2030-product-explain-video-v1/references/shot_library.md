# 镜头语言库（远景/近景/细节 + 应用场景）

> 本文件为「AIST2030 产品讲解视频」的镜头选型真源。运镜 ID 沿用 camera-prompt 内置 50 种库（`references/camera_library_50.md`）与 14 大类（`references/industry_camera_map.md`），**禁止另写一套**。此处只做「镜头类型 → 运镜子类 → 代表 ID → 适用场景」的映射与「应用场景」镜头补充。

## 一、三类基础镜头

| 镜头类型 | 目的 | 优先运镜子类 | 代表运镜 ID |
|---|---|---|---|
| 远景（应用场景） | 建立使用情境，让人代入 | 平移扫面细节(06–10) / 转场衔接(46–50) | 06 平行扫面、08 对角滑入、46 中心冲镜 |
| 近景（产品整体） | 第一印象，立体结构 | 基础环绕推拉(01–05) / 主体旋转(11–15) | 01 定轴小环绕、05 螺旋升降环绕、11 转盘自转跟拍 |
| 细节（材质/logo/接口） | 证明品质，放大卖点 | 微距肌理质感(21–25) / 光影联动(26–30) | 21 微距贴滑、23 切面反光扫移、28 轮廓光环绕 |

## 二、应用场景镜头库（远景扩展）

当用户提供「场景图」或指定「应用场景」时，用以下组合把产品放进真实情境：

| 场景 | 适配行业 | 镜头组合 | 出片节点 |
|---|---|---|---|
| 宴席/餐桌（酒水、食品） | 酒水饮料/食品茶饮 | 远景环境横移(06) → 产品入镜推进(03) → 细节举杯微距(21) | HyperFrames 合成 或 千帆 text2video |
| 厨房台面（家电/食品） | 家居日用/食品 | 俯拍全景(12) → 产品特写(01) → 使用动作跟拍(07) | HyperFrames / 千帆 |
| 办公桌面（3C/文具） | 3C数码/潮玩文创 | 桌面横移(06) → 产品推近(02) → 接口微距(21) | HyperFrames / 千帆 |
| 佩戴/上身（珠宝/箱包/服装） | 珠宝首饰/皮具箱包/服装 | 远景人物虚化(31移轴) → 产品特写(01) → 材质反光(23) | HyperFrames 合成 |
| 户外/手持（运动/户外用品） | 金属制品/通用 | 低角度英雄镜头(11) → 手持跟随(07) → 细节(21) | HyperFrames / 千帆 |

**场景图缺失时的兜底**：
- 无场景图但文案描述了场景 → 用 HyperFrames 把产品 PNG 抠图合成进 CSS 场景（渐变背景 + 投影 + 环境光）；
- 既无场景图又需真实感 → 千帆 text2video（prompt 描述场景+产品），但质量弱于实拍合成，需在成片标注「场景示意」。
