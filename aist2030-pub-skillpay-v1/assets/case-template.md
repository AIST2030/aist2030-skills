# 效果案例模板（最多 3 个）

> 上架 SkillPay 时商品资料需 3 个案例：核心能力 / 典型行业场景 / 边界说明。
> 下方为本技能自身（`AIST2030-pub-skillpay-v1`）的填写示例，可作仿写样板。

## 本技能自身发布填写（SkillPay）

- **Slug（不可改）**：`aist2030-pub-skillpay-v1`
- **显示名称**：**SkillPay 付费上架助手**（直观表达「定价 + 备料 + 过审」能力）
- **图标建议**：货架/价签风格图标，品牌色建议橙蓝（交易 + 信任），或复用 SkillPay 主色
- **计费模式**：`per_call`（按调用量计费）
- **建议单价**：**0.20 元/次**（20 分）。理由：轻量审查/生成类服务，价位适中利于通过率与转化；可按同类微调
- **版本号**：`1.0.0`
- **变更说明**：首次发布：基于 SkillPay 官方更新日志（v0.1–v0.8）实现的付费 Skill 上架助手，覆盖计费模式决策、上架备料、发布门禁、支付兜底与上架后经营

### 案例 1 —— 核心能力（定模式 + 备料）

- **场景标题**：一个 Skill 从「能跑」到「能卖」的一站式备料
- **场景描述**：把待发布的 Skill 文件夹交给本技能，自动判定买断 / 订阅 / 免费，产出可直接复制的上架备料表（Slug、显示名、图标、版本、变更说明、3 个案例、补充材料），并逐项跑发布前门禁。
- **示例问题**：「帮我把这个 Skill 挂到 SkillPay 上卖，资料一起准备好」
- **触发条件**：用户提到「Skill 上架 / 付费 Skill 发布 / 上架资料怎么填」。

### 案例 2 —— 典型行业场景（独立开发者变现）

- **场景标题**：独立开发者把自用工具 Skill 商业化
- **场景描述**：开发者手上有好用的内部 Skill，却不知道定价与模式。本技能给出模式对比表与建议价位，并点出必须先做「即刻收」协议签约、否则网页支付不可用这类容易踩的坑，避免上架后被卡。
- **示例问题**：「我这个工具 Skill 定多少钱？买断还是订阅？」
- **触发条件**：用户询问定价、计费模式、收益结构或订阅制优劣。

### 案例 3 —— 边界 / 进阶说明

- **场景标题**：只做上架准备与合规自检，不代提交、不代付款
- **场景描述**：明确本技能只输出备料、门禁清单与支付兜底方案，不代替用户完成提交、签约与付款；平台费率、分成、审核时长等官方未载明的信息一律标注「待核实」，规则以官方更新日志 https://skillpay.alipay.com/changelog 为准。避免用户误以为本技能能直接上架。
- **示例问题**：「你能直接帮我把 Skill 提交上架吗？」
- **触发条件**：用户询问权限边界、平台规则出处或结算细节时，据此澄清。
