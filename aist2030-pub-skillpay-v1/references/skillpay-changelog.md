## 二、逐版明细

### v0.8 · 2026-09-29 · 网页支付上线，买断权益同步升级
- 新增网页支付：Agent 支付未能完成时，可通过网页继续完成购买
- 新上传的 Skill 需完成「即刻收」协议签约，以支持网页支付
- 升级一次性买断制 Skill：一次购买即可下载该 Skill 的全部版本
- 支持下载已集成支付能力的 Skill 压缩包

### v0.7 · 2026-09-10 · 支付体验与云端保护优化
- 提升支付端到端成功率，减少购买失败
- 首次支付时一并完成钱包绑定与付款，无需提前绑定
- 扫码支付后自动确认结果并继续安装，无需手动输入「已支付」
- 针对典型使用场景优化云端保护效果（更接近本地运行）

### v0.6 · 2026-08-31 · 商品详情支持补充材料
- 支持创作者上传补充材料，丰富商品详情内容
- 发布第二篇 Blog《Skill 的价值，从哪里来？》

### v0.5 · 2026-08-27 · 用户视角与交易体验上线
- 新增用户视角：集中查看已购买的 Skill、历史订单及订单状态
- 支持用户对购买过的 Skill 进行评价
- 升级个人货架与商品详情，优化展示和购买体验
- 升级订单经营数据

### v0.4 · 2026-08-20 · 开发者货架与多版本管理上线
- 新增 Skill 多版本管理，支持持续迭代与商品维护
- 新增开发者公开货架，集中展示与分发 Skill
- 支持打造个人主页，建立个人品牌
- 全新交互与视觉设计（以 Agent 的能力文件夹为核心概念）

### v0.3 · 2026-08-13 · SkillPay 全新官网上线
- 全新升级官网视觉与浏览体验
- 新增 Skill 商品、Blog 与更新日志展示

### v0.2 · 2026-08-10 · 订阅制付费与云端保护上线
- 新增 Skill 订阅制付费，订阅有效期内可持续使用
- 新增云端保护能力：订阅用户无需获取完整 Skill 原文
- 支持订阅权益校验、到期失效与续费引导
- 支持订阅订单与权益状态管理

### v0.1 · 2026-07-31 · SkillPay 首个版本上线
- 支持 Skill 一次性付费购买，付款成功后自动交付完整 Skill
- 支持开发者查看和管理已发布的 Skill 商品
- 支持交易款项实时到账
