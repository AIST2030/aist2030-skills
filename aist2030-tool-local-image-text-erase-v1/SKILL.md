# 本地图片去文字（保底色版）

## 什么时候用

用户给一张**已经排好版的成品图**（视频封面、海报截帧、带水印的图），只要求去掉上面的文字，
但要求**底图不能变形、底色块不能改色**。

## 路由：先判断该不该走本地

| 场景 | 走法 |
| --- | --- |
| 照片/实景/复杂纹理背景上的文字 | 直接调内置 `buddy-image-processing` 的 `erase`，快且够用 |
| **纯色块/渐变底 + 大字标题**（海报、视频封面、综艺字卡） | **必须走本地**（本文流程）。AI 重绘会把底色块一起改坏 |
| 二维码、精确图形 | 永远本地合成，AI 必拉伸变形 |

实测翻车案例：一张「蓝块 + 红块 + 白字」的封面，AI `erase` 后 → 红块整块变灰、
留下一个白色椭圆残影、尺寸还从 1242×558 被改成 1248×560。本地重做才干净。

## 正解算法（已验证）

`scripts/erase_text_local.py`，五步：

1. **文字 mask**：`min(RGB) > 105` 且 `max-min < 115`（亮且低饱和 = 白色字）。
2. **保护原设计光效**：对 mask 做连通域分析，`宽高比 > 8 且 高 < 30` 的细长横条是原图自带的
   高光/发光条，**必须挑出来保护**，否则会被当成文字一起擦掉。
3. **擦除带**：`dilate(mask, 椭圆核 45×45)` 罩住文字描边和投影；再把保护条位置从擦除带里抠掉。
4. **打底**：`cv2.inpaint(..., INPAINT_TELEA, radius=20)`。
5. **收尾**：对 inpaint 结果做 `GaussianBlur(sigma=7)` 抹掉分块感，再用
   `alpha = GaussianBlur(擦除带, sigma=4)` 羽化合成。边界无硬缝。

```bash
"C:/Users/Administrator/.workbuddy/binaries/python/envs/default/Scripts/python.exe" \
  scripts/erase_text_local.py <源图> <输出名（不带扩展名）>
```

## 选哪个脚本：基础版 vs 进阶版

| | `erase_text_local.py`（基础版） | `erase_text_blocks.py`（进阶版） |
| --- | --- | --- |
| 算法 | mask + `inpaint` + 低频平滑 + 羽化 | 按色块**自适应**：锚点充足 → 逐层扩散；不足 → 曲面拟合兜底 |
| 适用 | 文字面积占比**不大**（水印字、小标题、局部短句） | 文字**大面积横贯色块**（大号标题占满整块） |
| 弱点 | 大面积擦除会留**云斑 + 竖条 + 发灰**（邻域扩散还原不出块级渐变） | 参数更多，纯照片底不适用 |

**判断口诀**：拿基础版跑一遍，若填充区出现云斑/竖条/发灰 → 换进阶版。
两者用法完全相同：`python <脚本> <源图> <输出名（不带扩展名）>`，均同时出 PNG+JPG。

### 进阶版为什么这么设计（6 个实测结论，别改回 inpaint）

1. inpaint 大面积擦除只能从邻域扩散，而设计稿底色是"整块缓变"，还原不出块级渐变 → 云斑/竖条/发灰。
2. 全局多项式拟合会留**文字形状鬼影**：文字外围淡色光晕不是纯白，抓不进 mask 却污染拟合样本；低阶曲面也跟不动复杂渐变（红块 3 阶残差仍 19/255）。
3. 此类封面文字常带**暗投影**，实测延伸 **40~60px**。锚点落进投影 → 填充值被拉暗 → "文字形状暗轮廓"。
4. 不同色块干净锚点差别极大（蓝块 60px 外仍有 21% 干净像素；红块横贯全宽、8px 外都凑不够）→ **必须按色块自适应**。
5. **二值锚点 + 小核逐层扩散 > 一次性大核加权平均**：软权重/大 sigma 让远处像素参与加权 → 洞内被平均成偏亮值（浅雾）；逐层推进等价于由边界值决定的调和内插，不跨尺度串色。
6. **洞越小内插越准**：锚点半径是"避开投影"与"别把洞撑太大"的权衡，实测 **45px** 为较优点。

> 锚点筛选用**严格色相判据**（"某通道显著高于另一通道"），不用纯距离阈值：白色字及其抗锯齿边缘（如 `(208,219,223)`、`(101,124,192)`）天然不满足该判据，被干净排除。
>
> 关键常量（脚本顶部）：`BRIGHT=105, SATMAX=115, SIGMA=10.0, ITERS=260, DEN_T=0.45, CLASS_DIFF=20, TARGET_RATIO=0.15, ANCHOR_HI=45, ANCHOR_LO=8, FIT_DEG=2`。

### 进阶版的三个编码坑（已在脚本注释固化）

| 坑 | 症状 | 修法 |
| --- | --- | --- |
| `w[:,:,None]` 是单通道 | `GaussianBlur` 返回 2 维，与三通道相除广播失败 | 用 `np.dstack([w,w,w])` 铺成三通道 |
| `distanceTransform` 在 mask **内部**为 0 | 权重写反 → 文字原样保留 | alpha 用 `1 - clip(dist/R)`，不是 `clip(dist/R)` |
| `np.mgrid` 出二维坐标 | `np.stack` 堆错轴 → matmul 维度不匹配 | 做多项式项矩阵前先 `ravel` |

## 三个已踩过的坑（别再试）

| 做法 | 结果 |
| --- | --- |
| 逐行水平插值（取文字左右两点连线填充） | **水平条纹 + 文字鬼影**。底色是水平渐变时，行内参考点相距 700px，线性近似还原不了非线性渐变 |
| 逐列垂直插值 | **竖直"窗帘"条纹**。列间参考点落在文字描边上，列与列不连续 |
| 金字塔扩散 push-pull | **云斑补丁感**。低频扩散填出来的区域太平，和周围质感差一截 |

补丁感/云斑的通用解法就是上面第 5 步的「低频平滑 + 羽化」。

## 验收（必做，别只看缩略图）

1. **白色残留计数**：擦除带内统计 `min>105 且 max-min<60` 的像素，应≈0。
   阈值必须用 `<60` 而不是 mask 用的 `<115`，否则底色块偏亮的部位
   （如亮蓝 `#7b8fd7`，sat≈92）会被误报成残留。
2. **1:1 局部裁剪对照**：把原图/结果的文字区各裁一块**按原始像素**上下拼一张对照图再看。
   整图缩略显示会把 1px 级的条纹糊掉，也容易把小瑕疵放大成"伪影"，
   一律以 1:1 裁剪为准。
